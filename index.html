        طريقة الربط (مرة وحدة · 3 دقائق)
        

          
    
            
  1. افتح الشيت حقك من الكمبيوتر ← من القائمة Extensions ← Apps Script.
    2. 
            
  2. احذف الكود الموجود والصق الكود الجديد (زر «نسخ الكود» تحت) ← اضغط حفظ 💾.
    3. 
            
  3. من فوق اختر الدالة setup واضغط Run ← وافق على الصلاحيات (Sheets + Drive).
    4. 
            
  4. أول مرة: Deploy ← New deployment ← النوع Web app ← Execute as: Me ← Who has access: Anyone ← Deploy وانسخ الرابط.
    5. 
            
  5. عندك ربط قديم (شيتك فيه تبويب Villas)؟ Deploy ← Manage deployments ← ✎ Edit ← Version: New version ← Deploy. الرابط يبقى نفسه، وتلقاه في نفس الشاشة باسم Web app URL.
    6. 
            
  6. الصق الرابط فوق واضغط «حفظ وربط». بتنضاف تبويبات Observations و Summary و Custom Templates، وبيانات Villas القديمة ما تنمس.
    7.
