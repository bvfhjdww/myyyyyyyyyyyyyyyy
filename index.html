خطوة وحدة عشان تنحفظ ملاحظاتك بالشيت

الشيت مربوط، لكن كود Apps Script اللي داخله هو القديم (حق الفلل والقوالب) وما يعرف يحفظ الملاحظات. ملاحظاتك محفوظة بالجوال (0 بانتظار الرفع) وبترتفع لحالها أول ما تحدّثه.

  1. اضغط نسخ الكود الجديد تحت.
  2. افتح الشيت (من الكمبيوتر أسهل) ← Extensions ← Apps Script ← احذف الكود القديم كله والصق الجديد ← Save
  3. من القائمة اللي فوق اختر setup ← Run ← وافق على الصلاحيات. إذا طلع لك تحذير من Google: Advanced ← Go to … ← Allow
  4. Deploy ← Manage deployments ← ✎ ← Version: New version ← Deploy
    (لا تختار New deployment عشان يبقى نفس الرابط)
